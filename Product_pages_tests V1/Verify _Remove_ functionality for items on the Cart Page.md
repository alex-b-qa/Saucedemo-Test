# Test: Verify "Remove" functionality for items on the Cart Page

## Objective
Verify you can remove an item from the cart on the Cart Page

## Precondition
- User is logged in as standard_user
- User has added one product to the cart
- User is on the cart page (cart.html)

## Steps
1. Click "Remove" button
2. Observe if an item is still in the cart
3. Observe the cart icon badge in the header
4. Refresh browser

## Expected Results
- Item is removed from cart
- Cart is empty and remains empty after refresh
- Quantity notification is removed from cart icon

## Priority
High
